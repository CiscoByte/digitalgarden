Complete this labs as follows:

1. Scan the Company servers for vulnerabilities.
    1. From the Favorites bar, select **Zenmap**.
    2. At the prompt, type **nmap x.x.x.x/24**.
    3. Select **Scan**.
2. Find the network vulnerabilities in the output and then answer the questions.

Found Vulnerability on server! 6 machines are public facing and have telnet open.

Telnet transmits all data—including usernames, passwords, and executed commands—in plain text.
